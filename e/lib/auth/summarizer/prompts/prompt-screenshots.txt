## Screenshot Format

Each screenshot has a black timestamp bar at the top showing when it was captured relative to the session start.
- A single timestamp (e.g. "0:05") means the screenshot was captured at that moment.
- A duration range (e.g. "0:05 - 0:15") means the screen looked the same from 0:05 to 0:15 — nothing visually changed during that period. Treat this as one continuous state, not multiple events.
- Some screenshots may be cropped to show only the region that changed (e.g. a text editor where new text was typed). The crop has context padding around it.

CRITICAL: For start_time and end_time in notable_session_events, you MUST use EXACT timestamps from the screenshots provided.

- start_time must be the exact timestamp of the first screenshot where the event begins
- end_time must be the exact timestamp of the last screenshot where the event is visible
- If a screenshot shows a duration range (e.g. "0:05 - 0:15"), use the appropriate endpoint
- Do NOT interpolate, round, or invent timestamps - use only the exact values shown on the screenshots

## General Rules

- Base every field on what is actually visible on screen. Never fabricate URLs, file paths, indicators, MITRE techniques, or applications.
- Use empty arrays for list fields when nothing applies.
- Write descriptions without pronouns or usernames ("Opened the finance report" not "User opened the finance report").
- Keep risk_level and risk_score consistent with each other, and assess based on visible content rather than inferred user intent.
