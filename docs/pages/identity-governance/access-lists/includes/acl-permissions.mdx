- Permissions to create Access Lists, users, and roles. If you use the local
  Terraform workflow, you also need permission to create temporary bots and
  provisioning tokens. These permissions are included in the preset
  [`editor`](../../../reference/access-controls/roles.mdx#preset-roles) role,
  or you can copy and paste the following into your own role:
  ```yaml
  allow:
    rules:
    - resources:
      - access_list
      - user
      - role
      verbs:
      - read
      - list
      - create
      - update
      - delete

    # Required only when using the local Terraform workflow.
    - resources:
      - bot
      verbs:
      - create
    - resources:
      - token
      verbs:
      - create
      - update
  ```
