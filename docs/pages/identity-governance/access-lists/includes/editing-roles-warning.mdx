<Admonition type="warning" title="Editing the supporting roles">
Avoid directly modifying the supporting roles for this Access List. Keep their
names and their `teleport.internal/access-list-preset*` labels unchanged — the
Web UI Access List editor and `tctl acl update` rely on both to recognize them.

To change what the list grants:

- **Web UI** — from the sidebar menu, click **Identity Governance** >
  **Access Lists**, click the target Access List, open the **Access Definition**
  tab, then click **Edit Access**.
- **`tctl`** — rerun
  [`tctl acl update`](../../../reference/cli/tctl.mdx#tctl-acl-update) with the
  resource flags you want.
- **Terraform** — rerun
  [`tctl acl update`](../../../reference/cli/tctl.mdx#tctl-acl-update) with the
  resource flags you want and `--iac terraform` to regenerate the configuration,
  then apply it.

The Web UI editor and `tctl acl update` support only a limited subset of role
fields. Editing the roles directly (via Terraform, `tctl`, or the role editor)
may make them incompatible with those tools. From that point on you must manage
the roles directly for the rest of the Access List's life.
</Admonition>
