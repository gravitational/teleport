Teleport protects your organizations on Git hosting platforms such as GitHub.
Users sign in with their Teleport identity, and Git commands and platform CLI
tools such as `gh` go through Teleport with short-lived credentials instead of
long-lived personal access tokens and SSH keys. Teleport records this activity
in its audit log.

The guides in this section show you how to enroll your organizations in
Teleport and configure access controls for them.
