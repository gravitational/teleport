<Admonition type="note" title="TLS routing">
This guide assumes your Teleport cluster uses TLS routing
(`proxy_listener_mode: multiplex`), where all client traffic goes through the
proxy web address on port `443`. If your cluster uses separate listener ports,
note that `tsh login` and web UI access still use the HTTPS port (typically
`443` or `3080`), while service-to-service connections use dedicated ports:
`3025` for the Auth Service, `3024` for the reverse tunnel, and `3023` for
the SSH proxy. Replace the port in `proxy_server` or `--auth-server` settings
accordingly, but keep the web port for `tsh login --proxy=`.
</Admonition>
