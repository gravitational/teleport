<details>
<summary>Connecting with TLS routing disabled</summary>

This guide's commands assume your Teleport cluster uses TLS routing
(`proxy_listener_mode: multiplex`), where all client traffic goes through the
proxy web address on port `443`. If you're not sure whether this applies to
your cluster, check with whoever manages it.

If your cluster uses separate listener ports instead, replace port `443` in
the commands below with the port for the Auth Service:

```code
$ tctl status --auth-server=teleport.example.com:3025
```
