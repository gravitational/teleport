<Admonition type="tip" title="Single-node deployments">
If you are running the Database Service on the same host as the Teleport Proxy
Service, the reverse tunnel may fail to connect through the proxy's public
address due to NAT hairpinning limitations in cloud environments. To resolve
this, add your proxy domain to `/etc/hosts` pointing to `127.0.0.1`, or enable
TLS routing (`proxy_listener_mode: multiplex` in your cluster networking
configuration) which routes traffic locally without the reverse tunnel.
</Admonition>
