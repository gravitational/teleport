The Linux, macOS, and Docker installation commands below use
[`jq`](https://jqlang.org/download/) to read your Teleport cluster's version
from the Proxy Service. Install `jq` before continuing if you don't already
have it.

<Tabs>
<TabItem label="Linux">

The Event Handler plugin is provided in `amd64` and `arm64` binaries for downloading.
Replace `ARCH` with your required version.

This command queries your Teleport Proxy Service directly to detect the
version of your Teleport cluster, so the plugin version you download always
matches your cluster. Replace <Var name="teleport.example.com:443" /> with the
address of your Teleport Proxy Service:

```code
$ EVENT_HANDLER_VERSION=$(curl -s https://<Var name="teleport.example.com:443" />/v1/webapi/find | jq -r '.server_version')
$ curl -L -O https://cdn.teleport.dev/teleport-event-handler-v${EVENT_HANDLER_VERSION}-linux-<Var name="ARCH" />-bin.tar.gz
$ tar -zxvf teleport-event-handler-v${EVENT_HANDLER_VERSION}-linux-<Var name="ARCH" />-bin.tar.gz
$ sudo ./teleport-event-handler/install
```

</TabItem>

<TabItem label="Docker">
Ensure that you have Docker installed and running. This command queries your
Teleport Proxy Service directly to detect the version of your Teleport
cluster, so the image tag you pull always matches your cluster. Replace
<Var name="teleport.example.com:443" /> with the address of your Teleport
Proxy Service:

```code
$ EVENT_HANDLER_VERSION=$(curl -s https://<Var name="teleport.example.com:443" />/v1/webapi/find | jq -r '.server_version')
$ docker pull public.ecr.aws/gravitational/teleport-plugin-event-handler:${EVENT_HANDLER_VERSION}
```

</TabItem>

<TabItem label="Helm">

To allow Helm to install charts that are hosted in the Teleport Helm repository, use `helm repo add`:

```code
$ helm repo add teleport (=teleport.helm_repo_url=)
```

To update the cache of charts from the remote repository, run `helm repo update`:

```code
$ helm repo update
```

</TabItem>
<TabItem label="Build via Go">

You will need Go >= (=teleport.golang=) installed.

Run the following commands:

```code
$ git clone https://github.com/gravitational/teleport.git --depth 1 -b branch/v(=teleport.major_version=)
$ cd teleport/integrations/event-handler
$ make build
```

The resulting executable will have the name `event-handler`. To follow the
rest of this guide, rename this file to `teleport-event-handler` and move it
to `/usr/local/bin`.

</TabItem>
