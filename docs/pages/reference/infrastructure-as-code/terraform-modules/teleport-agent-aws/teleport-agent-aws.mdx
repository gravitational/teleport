## Teleport Agent Services Deployment on AWS ECS

This module deploys a Teleport Database Service to AWS as an ECS task. It can
generate the configuration, IAM permissions, and Teleport IAM join token for
the Database Service.
It is not intended to deploy a Teleport cluster or its Auth Service and Proxy
Service control plane. This module does not provision the persistent backend and
audit event storage, load balancing, DNS, or TLS certificates required to
operate a self-hosted Teleport cluster.

Set `var.region` on each module instance to deploy Database Services across
multiple Regions using a single AWS provider configuration.

By default, the module creates an outbound security group for the Database
Service and a database-access security group that allows traffic from the
outbound group. The database-access group is returned as
`database_security_group_id` so it can be attached to databases. As an
alternative, set `database_service.database_security_group_ids` to have the
module add ingress rules to existing database security groups, sourced from
the outbound Database Service security group.

For an existing VPC, the module discovers its subnets and classifies them by
their effective route tables' IPv4 default routes. It deploys to up to 16
private subnets whose default routes target AWS NAT gateways when available;
otherwise, it deploys to up to 16 public subnets whose default routes target an
AWS internet gateway and assigns public IP addresses to the ECS tasks. The
deployment fails when neither class provides internet access.

When creating a VPC in the same Terraform apply, pass its `private_subnet_ids`
or `public_subnet_ids` outputs to bypass subnet discovery. Private subnets are always
preferred when both are provided.

## Prerequisites
- An existing Teleport cluster with Auth Service and Proxy Service
- A reachable Teleport Proxy Service endpoint
{/* lint ignore absolute-docs-links */}
- A supported join method and credentials that the agent can use to join the
  cluster. Database Service deployments create an IAM join token by default.
  See the [Join Methods and Token Reference](https://goteleport.com/docs/reference/deployment/join-methods/)
  for other supported join methods and creating tokens.
